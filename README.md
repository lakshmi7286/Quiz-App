# Quiz App

A simple and interactive quiz application built using HTML, CSS, and JavaScript. Users can answer multiple-choice questions, receive instant feedback, and view their final score at the end of the quiz.

## Live Demo

🔗 https://lakshmi7286.github.io/Quiz-App/

## Features

- Multiple-choice questions
- Instant correct/incorrect feedback
- Score calculation
- Next question navigation
- Play Again option
- Responsive user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
